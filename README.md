# Jarvis AI

Jarvis AI is a **console-based virtual assistant** built in Python. It is integrated with **LiveKit** (for real-time communication) and uses a **Google API Key** for AI or cloud-based features.

---

## 🚀 Features

- Voice and text interaction (depending on setup)  
- Real-time communication via LiveKit  
- Ability to connect to Google APIs for AI / data access  
- Easily extendable: you can add your own commands, modules, and integrations  
- Lightweight: runs from console (no heavy GUI required)

---

## 📦 Prerequisites / Requirements

- Python 3.8+ (or the version you're using)  
- A valid **Google API Key** (for whichever Google services you are using)  
- Internet connectivity (for API calls)
